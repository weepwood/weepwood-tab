# 工作空间壁纸与浏览器同步

## 工作空间独立壁纸

在“设置 → 壁纸”中可以切换壁纸应用范围：

- **全部空间**：修改全局壁纸、模糊和遮罩。
- **当前空间**：只修改当前工作空间；没有独立设置时继续跟随全局。
- 点击“恢复跟随全局”可以删除当前空间的覆盖配置。

工作、学习、生活和专注空间可以分别使用内置壁纸或本地上传图片。

## 浏览器账号同步

Chrome/Edge 扩展版在“设置 → 数据”中提供浏览器账号同步：

- **立即上传**：把当前轻量配置写入 `chrome.storage.sync`。
- **从同步恢复**：读取同一浏览器账号中的备份并覆盖当前轻量配置。
- **自动同步**：本地数据变化后延迟写入同步存储。
- **删除云端备份**：删除 Weepwood Tab 写入的同步分片。

为避免超过浏览器同步配额，下列大体积数据不会上传：

- 本地上传壁纸
- 本地上传的网站图标
- 未来图片组件中的原始图片数据

从同步恢复时，同一设备已有的本地图片资源会尽量保留。同步数据采用约 5,000 字符的分片保存，避免单项体积过大。

## 搜索计算

搜索框现在可以直接计算常见表达式，例如：

- `12 * (8 + 2)`
- `100 / 4`
- `15% * 200`

计算过程使用内置表达式解析器，不执行输入的 JavaScript 代码。

## 世界时钟

世界时钟右上角提供城市选择，可从东京、上海、新加坡、伦敦、巴黎、纽约、洛杉矶和悉尼中选择 1—4 个城市。设置保存在当前浏览器中。
